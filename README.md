# Zhefei Huang Portfolio

This is the source folder for Zhefei Huang's portfolio website.

Main files:

- `index.html` is the homepage.
- `css/polish.css` is the final visual override layer for layout, typography, responsive behavior, and project readability.
- `js/main.js` contains project data, bilingual copy, project-room rendering, tabs, lightbox, sound, and language switching.
- `projects/` contains the older direct project pages.
- `images/`, `videos/`, `audio/`, and `files/` contain the website media assets.
- `HOW_TO_EDIT_CN.md` is a beginner-friendly Chinese guide for editing the site later.
- The free public site should use GitHub Pages. No custom domain is required.

Local preview:

```powershell
python -m http.server 5173
```

Then open:

```text
http://127.0.0.1:5173/index.html
```
